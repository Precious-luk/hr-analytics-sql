# HR Analytics Project Using SQL

## Project Overview

This project uses SQL to analyse employee demographics, salaries, occupations, and departmental information in the Parks and Recreation dataset.

The objective is to practise SQL analysis and explore workforce composition, salary distribution, and employee rankings while connecting query results to potential HR business decisions.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Business Questions

This project explores questions such as:

1. How many employees are recorded in the database?
2. What is the gender distribution of employees?
3. What is the average employee age by gender?
4. Who are the youngest and oldest employees?
5. What is the average salary by department?
6. Which employees earn above the company-wide average salary?
7. How are employees distributed across salary bands?
8. Which occupations have the highest and lowest average salaries?
9. Who are the highest-paid employees in each department?
10. How do employee salary rankings differ using `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`?
11. How do salaries compare across employees and gender groups?

## SQL Concepts Demonstrated

* Filtering and sorting
* Aggregate functions
* `GROUP BY`
* `JOIN`
* Subqueries
* `CASE` statements
* Common Table Expressions (CTEs)
* Window functions
* `RANK()`, `DENSE_RANK()`, and `ROW_NUMBER()`
* `LEAD()`
* Running totals and salary comparisons

## Business Applications

The analysis demonstrates how SQL can help investigate workforce composition, compensation patterns, salary distribution, and departmental staffing. These insights can support HR reporting, workforce planning, and further compensation analysis.
